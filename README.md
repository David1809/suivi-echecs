# Mes parties d'échecs

Suivi et analyse des parties chess.com (PWA). Les données viennent d'une base Supabase protégée par un code d'accès.

- `docs/` : l'appli prête à servir (GitHub Pages, branche principale, dossier /docs)
- `src/` : sources (app.js, style.css, index.template.html)
- Reconstruire : `npm install` puis `node build.mjs` (génère docs/index.html)
